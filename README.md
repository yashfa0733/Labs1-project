 # Lab 1 — Developer Portfolio

**Course:** Web Technologies  
**Lab:** 1 — Web Development Environment + Developer Portfolio

## Project overview
A four-page responsive developer portfolio built with semantic HTML5 and external CSS.

## Pages
- `index.html` — Home
- `about.html` — About and skills
- `projects.html` — Three project cards
- `contact.html` — Contact form with built-in HTML validation

## Technologies
- HTML5
- CSS3
- JavaScript
- XAMPP / Apache
- Git and GitHub

## Run with XAMPP
1. Copy the `Lab1-Portfolio` folder into `C:\xampp\htdocs`.
2. Start Apache from XAMPP Control Panel.
3. Open `http://localhost/Lab1-Portfolio/` in your browser.

## Contact form note
The form demonstrates client-side HTML validation only. It does not send or store messages because a backend is outside the scope of Lab 1.
